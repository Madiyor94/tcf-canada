# Écrire — TCF Canada practice

A static TCF Canada writing-exam simulator. Create your own three-task exams, practise timed writing, see live word counts, and use the French-character table.

## Publish on GitHub Pages

1. Create a new public GitHub repository.
2. Upload all files from this folder, including the `.github` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. Push or commit to the `main` branch. The included workflow publishes the site automatically.

Your public link will be:

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

The site has no server and no API key. Exams and answers are saved only in each visitor's browser using local storage.
